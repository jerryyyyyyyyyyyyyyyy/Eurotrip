# Eurotrip 2026: 20 Days in the Alps & Italy

一個為四人歐洲自助旅行（奧地利、瑞士、義大利）量身打造的即時協作旅遊儀表板。透過此網頁，所有同行夥伴可以免登入、跨裝置即時共同編輯行程、預算與行李清單。

## 🌐 線上即時版 (Live Demo)
👉 [點此開啟 Eurotrip 儀表板](https://eurotrip-lac.vercel.app)
*(建議將此網址加入手機主畫面，作為旅途中的專屬 App 捷徑)*

## ✨ 核心特色與功能
* **⚡ 雲端即時同步 (Real-time Sync)**：導入 Firebase Realtime Database，任何人新增行李或修改預算，其他人的畫面會瞬間同步，無需重新整理。
* **🎒 協作打包清單**：支援動態分類與勾選狀態保存，四人可同時核對護照、轉接頭與歐元現金等裝備。
* **🗺️ 行程與預算追蹤**：視覺化呈現 20 天的跨國移動路線（維也納 → 瑞士 → 多洛米蒂 → 義大利），並即時計算團隊公費與個人開銷。
* **📱 跨平台響應式設計**：針對 iOS 與 Android 手機瀏覽器最佳化，方便在超市記帳或旅館核對裝備時單手操作。

## 🛠️ 開發技術棧 (Tech Stack)
* **前端介面**：HTML5, CSS3, Vanilla JavaScript (ES6+)
* **雲端資料庫**：Google Firebase Realtime Database (Web SDK)
* **版本控制與部署**：Git, GitHub, Vercel (CI/CD 自動化部署)
