#  Eurotrip 歐洲 20 天自由行規劃工具

一個為了歐洲三國（奧地利、瑞士、義大利）自助旅行所量身打造的前端網頁互動工具。透過此網頁，可以輕鬆管理、檢視並動態渲染行李打包清單與旅遊待辦事項。

## 🌐 線上展示
👉 [點此觀看我的歐洲行網頁](把你的Vercel公開網址貼在這裡)

## ✨ 特色與功能
* **動態行李打包管理**：支援分類新增行李項目（如：自訂類別、衣物、證件等），並可動態計算、更新已打包的數量。
* **鍵盤友善操作**：輸入框支援 `Enter` 鍵快速新增項目，優化使用者體驗。
* **響應式狀態保存**：即時更新網頁狀態（`PACKING_STATE`），確保資料同步。

## 🛠️ 開發技術
* **前端核心**：HTML5, CSS3, JavaScript (Vanilla JS)
* **DOM 操作**：利用 `querySelectorAll` 與事件監聽器（Event Listeners）實現動態 UI 渲染。
* **部署平台**：Vercel (與 GitHub 儲存庫自動連動)
